# dovi0129.github.io

Personal academic page of Minu Baek (백민우) — safe reinforcement learning and
industrial process control, Eco AI Lab, Hanbat National University.

Live at <https://dovi0129.github.io>.

## Layout

| File         | Purpose                                                    |
|--------------|------------------------------------------------------------|
| `index.html` | The whole document: about, research, publications, projects, software, activities, contact |
| `style.css`  | Classic-documentation styling: white ground, blue underlined links, text menus, rules |
| `site.js`    | Progressive enhancement only — TOC highlighting, `j`/`k` navigation, publication filter, copy buttons |

No build step, no dependencies, no web fonts, no analytics. Edit the files and
push; GitHub Pages serves them as they are. The page is readable with
JavaScript disabled and prints to five pages with the navigation removed.
